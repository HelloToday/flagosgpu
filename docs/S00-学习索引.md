## 命名与维护约定

`docs/S00-学习索引.md` 与 `docs/S01-赛前静态准备.md` 是共享资料；平台专题分别放入 `docs/MetaX/` 和 `docs/B1-V150/`，各自从 `S01-中文主题.md` 开始按形成顺序递增。编号只表示平台目录内的排序和阅读顺序，不等同于七阶段编号；后续文档继续放入对应平台目录。文件移动或重命名时同步更新本索引和站内链接，不保留空白占位文档。每个平台最高编号现存专题末尾维护唯一 A0/B1 四行结果、完整精度摘要与统计口径；按既有成果门槛或用户明确许可新建专题后立即整段迁移，旧文档只保留链接，并同步计划和索引。迁移已有结果不代表新方案通过验收。

专题文档随实质成果及相应验证形成，记录环境身份、实现、正确性与fallback、完整Level3、双场景统计和保留决定；未完成项就近标注。

发生阶段性实质进展时，更新阶段状态、文档状态和对应正文；同一成果的后续验证继续写入原专题。BI-V150 与 C500 分开陈述，4K/16K 和 Prefill/Decode 分开陈述，只有完成对应阶段出口后才把阶段标为完成。
